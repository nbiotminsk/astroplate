## 🚀 Стек и структура проекта

* **Frontend**: Astro 6 (SSG), React 19, Tailwind CSS 4, TypeScript.
* **Backend / API**: PHP 8.x в `public/api/` (включая Telegram-бот `public/api/telegram_bot/` и интеграции).
* **Хостинг / Деплой**: 
  * Ветка `main` — исходный код.
  * Ветка `deploy` — скомпилированная версия сайта (`dist/`), синхронизируемая с веб-сервером Plesk.
  * CI/CD: GitHub Actions с разделением на быстрый деплой API и полную сборку сайта.
